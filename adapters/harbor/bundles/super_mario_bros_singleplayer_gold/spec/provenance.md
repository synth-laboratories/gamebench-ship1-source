# Clean-room and redistribution boundary

This bundle distributes original Rust simulation code and geometric RGB
rendering only. It contains no ROM, dump, extracted level/map data, captured
frames, proprietary sprites, music, audio, or Nintendo asset encoding.

The optional local research oracle path is
`roms/Super Mario Bros. (Japan, USA).nes`. That path is gitignored and is never
needed by the build or verifier. Oracle observations may not be copied into
tracked files, fixtures, generated source, hashes-as-content, or the bundle.

The environment is a capability-oriented research port and must not be
described as Nintendo-content parity or an emulator.
